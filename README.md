# COMP 5120 - Database Systems I
Auburn University
The course focuses on the theoretical and practical aspects of relational database systems, including database analysis, design, and implementation. Topics include relational data modeling, SQL queries, database schema design, indexing, and query optimization.

## Course Topics

- Introduction to database systems
- Conceptual data modeling and database design
- Entity-Relationship (ER) diagrams
- Relational data models and database schemas
- Relational algebra
- Structured Query Language (SQL)
- Database queries and data retrieval
- Database indexing and data representation
- Query processing and optimization
- Database implementation and performance

## Assignments

Coursework focuses on designing relational databases, developing database schemas, writing SQL queries, and understanding how database systems store, retrieve, and process data.
